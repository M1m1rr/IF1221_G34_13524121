# IF1221_G34_13524121
Tugas Besar IF1221 Logika Komputasional 

- Gambaran singkat proyek <br>
  Praktikum ini merupakan implementasi simulasi permainan kartu tradisional bernama UNI yang dikembangkan menggunakan paradigma pemrograman logika berbasis bahasa Prolog. Tujuan utama dari proyek ini adalah melakukan pemodelan komputasional terhadap aturan-aturan non-konvensional yang bersifat spesifik (custom rules) ke dalam sekumpulan fakta dan aturan (rules) yang sistematis. Secara teknis, pengembangan simulasi ini mengintegrasikan berbagai konsep fundamental dalam mata kuliah IF1221 Logika Komputasional, yang meliputi manipulasi struktur data list, penerapan algoritma rekurens, serta pengendalian alur eksekusi melalui mekanisme cut, fail, dan looping. Selain logika permainan inti, fungsionalitas sistem diperluas dengan implementasi file processing yang memungkinkan persistensi data melalui fitur penyimpanan (save) dan pemuatan (load) status permainan dalam format dokumen tekstual. Seluruh siklus pengembangan dikelola secara kolaboratif menggunakan Version Control System (Git) melalui platform GitHub. Hal ini mencakup pengorganisasian struktur repositori yang terstandarisasi serta pemenuhan target fungsionalitas yang terbagi dalam beberapa tahapan strategis atau milestones. Melalui pendekatan ini, proyek berhasil mentransformasikan aturan permainan yang kompleks menjadi sebuah sistem perangkat lunak yang koheren, teruji, dan terdokumentasi dengan baik.
